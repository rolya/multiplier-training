# 🐣 Тренажёры

Статическое веб-приложение (только HTML + CSS + JS, без сборки и без сервера).
Все настройки и история тренировок хранятся в `localStorage` браузера.

Корневой `index.html` — список тренажёров. Каждый тренажёр лежит в своей папке
и работает независимо от остальных (свои файлы, свои ключи в `localStorage`).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная страница со списком тренажёров |
| `css/home.css` | Стили главной страницы |
| `multiplier/` | Тренажёр таблицы умножения |
| `number-composition/` | Тренажёр состава числа |

У каждого тренажёра одинаковая раскладка файлов:

| Файл | Что это |
|---|---|
| `index.html` | Страница настроек + кнопка «Старт» |
| `session.html` | Тренировка и экран итогов |
| `mistakes.html` | Печатная страница «Мои ошибки» |
| `js/storage.js` | Настройки и история сессий в `localStorage` |
| `js/matrix.js` (умножение) / `js/composition.js` (состав числа) | Генерация примеров и вариантов ответа |
| `js/settings-page.js` | Логика страницы настроек |
| `js/session-page.js` | Логика тренировки |
| `js/mistakes-page.js` | Логика страницы ошибок |
| `css/style.css` | Стили тренажёра (крупный «детский» интерфейс) |

## Как запустить

- **Локально:** открыть корневой `index.html` двойным кликом.
- **На хостинге/CDN:** залить папку как есть (GitHub Pages, Netlify, S3+CloudFront, любой статик-хостинг). Никакого бэкенда не нужно.

## Общие правила (одинаковы во всех тренажёрах)

- Правильный ответ → зелёная подсветка + кнопка «Далее».
- Неправильный → красная подсветка, «Далее» не появляется; можно выбирать снова, пока не будет зелёного.
- Ошибкой считается пример, где хотя бы одна попытка была неверной; такие примеры уходят в историю для повторения.
- Клавиатура: `Enter` — перейти к следующему примеру (в умножении ещё и «Проверить» в поле ввода).
- **Итоги:** счёт «правильно из всего», все примеры сессии целиком (зелёные — решённые сразу, красные — с ошибками), кнопки «Начать заново» (→ настройки) и «Мои ошибки».
- **Страница ошибок** открывается в новой вкладке со страницы настроек и с экрана итогов. Есть кнопка печати и переключатель «Скрыть ответы» — можно распечатать как обычный список примеров для решения.
- Кнопка «Очистить историю» на странице настроек удаляет историю и сохранённые ошибки этого тренажёра.

## ✖️ Тренажёр таблицы умножения — `multiplier/`

### Настройки

1. **Уровень** — 1: `7 × 3 = ?` (найти ответ); 2: `? × 3 = 21` или `7 × ? = 21` (найти пропуск, позиция пропуска случайная).
2. **Варианты ответа** — 0…10, по умолчанию 4. `0` — вместо кнопок поле для ввода.
3. **Количество примеров** — 1…100, по умолчанию 30.
4. **Работа над ошибками** — ошибки за последние `X` тренировок (по умолчанию 5) обязательно попадают в новую сессию.
5. **Умножение на 1** — можно исключить самые простые примеры.

### Как формируется сессия

1. Полная матрица (1…10 × 1…10 = 100 примеров, или 81 без единиц) перемешивается (shuffle).
2. Если включён фокус на ошибках — сначала в набор идут все прошлые ошибки (если их больше, чем примеров в сессии, берётся случайная часть).
3. Набор добирается случайными примерами из перемешанной матрицы до нужного количества.
4. Итоговый набор перемешивается ещё раз.

Примеры внутри сессии не повторяются (повтор возможен только если примеров запросили больше, чем есть в матрице).

### Данные в localStorage

- `mt.settings.v1` — настройки.
- `mt.history.v1` — последние 50 сессий: дата, счёт, список ошибок.

## 🧩 Тренажёр состава числа — `number-composition/`

Состав числа — это два слагаемых, дающих нужное число (`3 + 7 = 10`). В примере
скрыто одно или два места, и их нужно восстановить кнопками с числами.
Оба слагаемых всегда ≥ 1.

### Настройки

1. **Уровень**
   - **1** — один пропуск в слагаемом: `3 + ? = 9`, `? + 5 = 7` (один правильный вариант).
   - **2** — то же плюс пропуск в сумме: `6 + 3 = ?` (один правильный вариант).
   - **3** — два пропуска: `? + ? = 9`, `? + 5 = ?`, `2 + ? = ?` (два правильных варианта).
2. **Диапазон состава** — два значения, «с» и «до»: состав каких чисел тренируем. Каждое от 2 до 100, по умолчанию с 2 до 10. Можно взять только часть — например с 10 до 20 — или одно число (с 15 до 15). Меньше 2 состав из двух слагаемых не собрать, поэтому нижняя граница — 2. Если поднять «с» выше «до» (или опустить «до» ниже «с»), вторая граница подтянется сама.
3. **Варианты ответа** — 2…10, по умолчанию 4. Ручного ввода здесь нет, только кнопки.
4. **Количество примеров** — 1…100, по умолчанию 20.
5. **Работа над ошибками** — ошибки за последние `X` тренировок (по умолчанию 5) обязательно попадают в новую сессию. Берутся только те, чья сумма попадает в текущий диапазон.

### Как формируется сессия

1. Из последних `X` сессий берутся ошибки и фильтруются по текущему диапазону (`с ≤ сумма ≤ до`). `3 + 7` и `7 + 3` считаются одним составом.
2. Их количество вычитается из настройки «сколько примеров в тренировке» — так получается число новых примеров.
3. Столько чисел случайно выбирается из диапазона (числа, уже занятые ошибками, не берутся повторно, пока есть свободные).
4. Для каждого числа генерируется случайный состав (`a + b = число`).
5. Пропуски расставляются по шаблону уровня; итоговый набор перемешивается.

Если ошибок больше, чем примеров в тренировке, берётся случайная часть ошибок.
Если примеров запросили больше, чем чисел в диапазоне, разрешаются повторы чисел
(состав у них будет другой).

### Варианты ответа

Правильных вариантов ровно столько, сколько пропусков (один или два). Остальные —
«обманки»: числа от 1 до верхней границы диапазона (слагаемые ведь бывают и меньше
нижней границы). Принимается только такая обманка, с которой пример собрать верно
нельзя. Поэтому на экране всегда ровно одна правильная комбинация
(в `? + ? = 9` порядок двух чисел не важен).

Если верхняя граница совсем маленькая (например, 5), подходящих обманок может не
хватить — тогда кнопок будет меньше, чем указано в настройках.

### Правила ответа

- **Уровни 1 и 2** — один правильный вариант: как в умножении, верный вариант зеленеет и появляется «Далее», неверный краснеет и выключается, можно пробовать дальше.
- **Уровень 3** — два пропуска: числа выбираются по порядку, слева направо, и подставляются прямо в пример. Проверка идёт после второго выбора: верная комбинация — оба варианта зелёные и появляется «Далее»; неверная — оба красные, через секунду выбор сбрасывается и можно пробовать снова. Первый выбор можно отменить повторным кликом по кнопке.

### Данные в localStorage

- `nc.settings.v1` — настройки.
- `nc.history.v1` — последние 50 сессий: дата, счёт, уровень, границы диапазона, список ошибок.

Старые настройки с одним числом (`range`) читаются как верхняя граница, нижняя становится 2.
