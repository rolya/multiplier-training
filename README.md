# 🐣 Тренажёры

Статическое веб-приложение (только HTML + CSS + JS, без сборки и без сервера).
Все настройки и история тренировок хранятся в `localStorage` браузера.

Корневой `index.html` — список тренажёров и разделов. Каждый тренажёр лежит в своей
папке и работает независимо от остальных (свои файлы, свои ключи в `localStorage`).
Раздел — папка со своей страницей-списком, внутри которой лежит несколько
тренажёров (так устроен «Русский язык»).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Главная страница со списком тренажёров |
| `css/home.css` | Стили главной страницы |

## Как запустить

- **Локально:** открыть корневой `index.html` двойным кликом.
- **На хостинге/CDN:** залить папку как есть (GitHub Pages, Netlify, S3+CloudFront, любой статик-хостинг). Никакого бэкенда не нужно.

## Общие правила (одинаковы во всех тренажёрах)

- Правильный ответ → зелёная подсветка + кнопка «Далее».
- Неправильный → красная подсветка, «Далее» не появляется; можно выбирать снова, пока не будет зелёного.
- Ошибкой считается пример (в словарных словах — слово), где хотя бы одна попытка была неверной; такие примеры уходят в историю для повторения.
- В умножении, составе числа и словарных словах прошлые ошибки подмешиваются в новые тренировки. В сложении и вычитании — нет: там они только сохраняются, чтобы их распечатать и разобрать.
- Клавиатура: `Enter` — перейти к следующему примеру (в умножении ещё и «Проверить» в поле ввода).
- **Итоги:** счёт «правильно из всего», все примеры сессии целиком (зелёные — решённые сразу, красные — с ошибками), кнопки «Начать заново» (→ настройки) и «Мои ошибки».
- **Страница ошибок** открывается в новой вкладке со страницы настроек и с экрана итогов. Есть кнопка печати и переключатель «Скрыть ответы» — можно распечатать как обычный список примеров для решения.
- Кнопка «Очистить историю» на странице настроек удаляет историю и сохранённые ошибки этого тренажёра.

## ✖️ Тренажёр таблицы умножения — `multiplier/`

### Настройки

1. **Уровень** — 1: `7 × 3 = ?` (найти ответ); 2: `? × 3 = 21` или `7 × ? = 21` (найти пропуск, позиция пропуска случайная).
2. **Варианты ответа** — 0…10, по умолчанию 4. `0` — вместо кнопок поле для ввода.
3. **Количество примеров** — 1…100, по умолчанию 30.
4. **Работа над ошибками** — ошибки за последние `X` тренировок (по умолчанию 5) обязательно попадают в новую сессию.
5. **Умножение на 1** — можно исключить самые простые примеры.

### Как формируется сессия

1. Полная матрица (1…10 × 1…10 = 100 примеров, или 81 без единиц) перемешивается (shuffle).
2. Если включён фокус на ошибках — сначала в набор идут все прошлые ошибки (если их больше, чем примеров в сессии, берётся случайная часть).
3. Набор добирается случайными примерами из перемешанной матрицы до нужного количества.
4. Итоговый набор перемешивается ещё раз.

Примеры внутри сессии не повторяются (повтор возможен только если примеров запросили больше, чем есть в матрице).

### Данные в localStorage

- `mt.settings.v1` — настройки.
- `mt.history.v1` — последние 50 сессий: дата, счёт, список ошибок.

## 🧩 Тренажёр состава числа — `number-composition/`

Состав числа — это два слагаемых, дающих нужное число (`3 + 7 = 10`). В примере
скрыто одно или два места, и их нужно восстановить кнопками с числами.
Оба слагаемых всегда ≥ 1.

### Настройки

1. **Уровень**
   - **1** — один пропуск в слагаемом: `3 + ? = 9`, `? + 5 = 7` (один правильный вариант).
   - **2** — то же плюс пропуск в сумме: `6 + 3 = ?` (один правильный вариант).
   - **3** — два пропуска: `? + ? = 9`, `? + 5 = ?`, `2 + ? = ?` (два правильных варианта).
2. **Диапазон состава** — два значения, «с» и «до»: состав каких чисел тренируем. Каждое от 2 до 100, по умолчанию с 2 до 10. Можно взять только часть — например с 10 до 20 — или одно число (с 15 до 15). Меньше 2 состав из двух слагаемых не собрать, поэтому нижняя граница — 2. Если поднять «с» выше «до» (или опустить «до» ниже «с»), вторая граница подтянется сама.
3. **Варианты ответа** — 2…10, по умолчанию 4. Ручного ввода здесь нет, только кнопки.
4. **Количество примеров** — 1…100, по умолчанию 20.
5. **Работа над ошибками** — ошибки за последние `X` тренировок (по умолчанию 5) обязательно попадают в новую сессию. Берутся только те, чья сумма попадает в текущий диапазон.

### Как формируется сессия

1. Из последних `X` сессий берутся ошибки и фильтруются по текущему диапазону (`с ≤ сумма ≤ до`). `3 + 7` и `7 + 3` считаются одним составом.
2. Их количество вычитается из настройки «сколько примеров в тренировке» — так получается число новых примеров.
3. Столько чисел случайно выбирается из диапазона (числа, уже занятые ошибками, не берутся повторно, пока есть свободные).
4. Для каждого числа генерируется случайный состав (`a + b = число`).
5. Пропуски расставляются по шаблону уровня; итоговый набор перемешивается.

Если ошибок больше, чем примеров в тренировке, берётся случайная часть ошибок.
Если примеров запросили больше, чем чисел в диапазоне, разрешаются повторы чисел
(состав у них будет другой).

### Варианты ответа

Правильных вариантов ровно столько, сколько пропусков (один или два). Остальные —
«обманки»: числа от 1 до верхней границы диапазона (слагаемые ведь бывают и меньше
нижней границы). Принимается только такая обманка, с которой пример собрать верно
нельзя. Поэтому на экране всегда ровно одна правильная комбинация
(в `? + ? = 9` порядок двух чисел не важен).

Если верхняя граница совсем маленькая (например, 5), подходящих обманок может не
хватить — тогда кнопок будет меньше, чем указано в настройках.

### Правила ответа

- **Уровни 1 и 2** — один правильный вариант: как в умножении, верный вариант зеленеет и появляется «Далее», неверный краснеет и выключается, можно пробовать дальше.
- **Уровень 3** — два пропуска: числа выбираются по порядку, слева направо, и подставляются прямо в пример. Проверка идёт после второго выбора: верная комбинация — оба варианта зелёные и появляется «Далее»; неверная — оба красные, через секунду выбор сбрасывается и можно пробовать снова. Первый выбор можно отменить повторным кликом по кнопке.

### Данные в localStorage

- `nc.settings.v1` — настройки.
- `nc.history.v1` — последние 50 сессий: дата, счёт, уровень, границы диапазона, список ошибок.

Старые настройки с одним числом (`range`) читаются как верхняя граница, нижняя становится 2.

## ➕ Тренажёр сложения и вычитания — `plus-minus-trainer/`

Пример показывается целиком (`47 + 38 = ?`), ответ выбирается кнопкой. Работаем
только в пределах 100: сумма не больше 100, разность не меньше 0.

### Настройки

1. **Уровень** — можно включить один, два или все три сразу (хотя бы один должен остаться включённым). По умолчанию все три.
   - **1** — одно-двузначные числа **без** перехода через десяток: `45 + 23`, `45 + 3`, `58 − 23`, `58 − 20`.
   - **2** — двузначное и однозначное **с** переходом: `47 + 8`, `52 − 7`.
   - **3** — два двузначных **с** переходом: `47 + 38`, `52 − 37`.
2. **Варианты ответа** — 2…10, по умолчанию 4. Ручного ввода здесь нет, только кнопки.
3. **Количество примеров** — 1…100, по умолчанию 10. Под степпером сразу видно, сколько примеров достанется каждому уровню.
4. **Работа над ошибками** — только сколько последних тренировок показывать на странице «Мои ошибки» (по умолчанию 5). В новые тренировки ошибки **не** подмешиваются — примеры каждый раз новые.

### Как формируется сессия

1. Количество примеров делится между включёнными уровнями поровну; остаток отдаётся последним, более сложным уровням. 10 примеров на три уровня → 3 + 3 + 4.
2. Внутри уровня примеры делятся между сложением и вычитанием поровну; при нечётном количестве лишний пример случайно достаётся одному из действий.
3. Для каждого уровня и действия заранее строится полный пул допустимых примеров, перемешивается и из него берётся нужное количество. Повторы возможны только если примеров запросили больше, чем есть в пуле (в самом маленьком пуле их 324).
4. Итоговый набор перемешивается.

**Первое число всегда двузначное и не круглое** (единицы ≥ 1). Так его всегда есть
на что разложить, и обе подсказки получаются осмысленными. Второе число: на уровне
1 — одно- или двузначное, на уровне 2 — однозначное, на уровне 3 — двузначное.

### Варианты ответа

Правильный ответ один. Обманки — сначала типичные детские ошибки (ответ ±10 —
забыли переход через десяток, ±1, ±2, ±9, ±11, ±20), потом любые числа из 0…100.
Все кнопки разные, за 0 и 100 обманки не выходят.

### Подсказки

- **Переход через десяток** — мелкая строчка сразу под примером, видна всегда: «переход через десяток есть» или «перехода через десяток нет». Считается по единицам: в сложении единицы дают больше 9, в вычитании единиц первого числа не хватает.
- **Кнопка «Помочь»** раскрывает разбор именно этого примера по шагам — каждый шаг с пояснением, что делаем. Ответ она не прячет и ошибкой не считается, но отмечается: в итогах такой пример будет оранжевым, а в истории тренировок посчитается.

Способы разбора по уровням:

| Уровень | Сложение | Вычитание |
|---|---|---|
| 1 | **Метод 1 · по разрядам:** `40 + 20 = 60`, `5 + 3 = 8`, `60 + 8 = 68`.<br>**Метод 2 · по частям второго числа:** `45 + 20 = 65`, `65 + 3 = 68`. | **Метод 1 · по разрядам:** `50 − 20 = 30`, `8 − 3 = 5`, `30 + 5 = 35`.<br>**Метод 2 · по частям второго числа:** `58 − 20 = 38`, `38 − 3 = 35`. |
| 2 | **Разбиваем единицы:** одно действие `66 + 5 = 71`, под пятёркой нарисовано разбиение на `4` и `1`. | **Разбиваем единицы:** одно действие `45 − 8 = 37`, под восьмёркой нарисовано разбиение на `−5` и `−3`. |
| 3 | Те же два метода, что на уровне 1. У метода 2 второй шаг сам идёт через десяток — там и рисуется разбиение: `77 + 8 = 85`, под восьмёркой `3` и `5`. | **Метод 1 · сначала десятки, потом единицы по частям:** `52 − 30 = 22`, затем `22 − 7 = 15` с разбиением семёрки на `−2` и `−5`.<br>**Метод 2 · разность десятков минус разность единиц:** `50 − 30 = 20`, `7 − 2 = 5`, `20 − 5 = 15`. |

**Разбиение единиц рисуется «треугольником».** Действие остаётся одним, лишним
шагом его не разбиваем: под разбираемым числом расходятся две палочки, а на их
концах стоят части — сколько нужно до круглого десятка и остаток. В вычитании
части идут со знаком минус, чтобы было видно, что оба раза отнимаем.

```
66 + 5 = 71        45 − 8 = 37
       ╱ ╲                ╱ ╲
      4   1             −5   −3
```

Само место, куда встаёт разбиение, `arithmetic.js` отдаёт готовым: у шага есть
поле `split` с кусочками строки (`before`, `whole`, `parts`, `after`), а рисует
их `session-page.js` — палочки инлайновым SVG, само дерево вынесено из потока,
чтобы пример на строке не перекосило.

На уровне 2 способ по условию один. Если однозначное число как раз добивает до
круглого десятка (`47 + 3 = 50`), разбивать нечего — разбиение не рисуется.
На уровне 1 второй метод иногда просто повторил бы пример одним шагом
(например, `45 + 3 = 48`) — такой метод не показывается, остаётся только первый.

### Учёт подсказок

Открытие панели «Помочь» отмечается для примера один раз — сколько раз её ни
открывай и ни закрывай заново.

- **В итогах** цвет карточки: зелёная — решил сразу сам, **оранжевая** — решил верно, но с подсказкой (значок `✓ 💡`), красная — были ошибки. Ошибки важнее подсказки: если в примере была неверная попытка, карточка красная, даже если подсказку открывали.
- **В истории тренировок** на странице настроек — сколько примеров решено с подсказкой: «3 из 6 правильно, ошибок: 3, с подсказкой: 2 💡». Считаются все примеры, где открывали подсказку, в том числе решённые с ошибкой. Если подсказкой не пользовались, приписка не появляется.

### Данные в localStorage

- `pm.settings.v1` — настройки.
- `pm.history.v1` — последние 50 сессий: дата, счёт, `helped` (в скольких примерах открывали подсказку), включённые уровни, список ошибок (`a`, `b`, действие, уровень). В записях, сделанных до появления `helped`, поля просто нет — приписка про подсказку не показывается.

## 📖 Тренажёр словарных слов — `russian/vocabulary-words/`

Ребёнок видит словарное слово с пропусками (`авт..б..с`) и выбирает буквы кнопками.
Пропусков может быть несколько — они заполняются **по одному, слева направо**: у
каждого пропуска свой набор букв, текущий пропуск подсвечен сиреневым.

Раскладка файлов такая же, как у остальных тренажёров, плюс отдельный файл с данными:

| Файл | Что это |
|---|---|
| `js/words-data.js` | Датасет словарных слов (`VW.data`) |
| `js/words.js` | Сборка сессии, задания, варианты букв (`VW.core`) |
| `js/storage.js` | Настройки и история (`VW.store`) |

### Датасет

Одна запись — одно слово, поля ровно в том порядке, в каком их удобно читать:

```js
{ word: 'автобус', masked: 'авт..б..с', answers: ['о', 'у'], options: [['о', 'а'], ['у', 'о']] }
```

- `word` — правильное слово целиком;
- `masked` — слово с пропусками, пропуск помечен `..`;
- `answers` — правильные буквы по порядку слева направо;
- `options` — варианты вставки для каждого пропуска (первый — правильный).

Пустая строка `''` в `options` — вариант **«нет буквы»**: так проверяются удвоенные
согласные (`клас..` → «с» или ничего, `бел..рус..кий`, `су..б..та`).

Датасет проверяет сам себя: `VW.core.validate()` подставляет `answers` в `masked`,
сравнивает результат с `word` и следит, что правильная буква есть в `options`.
Страница настроек вызывает проверку при загрузке и пишет проблемы в консоль.

Сейчас в датасете **87 слов**: 43 для 2 класса и 44 для 3 класса, всего 121 пропуск.
Список 2 класса — по белорусской учебной программе; «Беларусь» и «Родина» пишутся
с большой буквы, так они и показываются ребёнку.

Некоторые слова есть в программе и 2, и 3 класса (`морковь`, `помидор`). Если
включены оба класса, слово всё равно попадает в тренировку один раз — слова
не повторяются независимо от класса.

### Настройки

1. **Класс** — 2 и/или 3 класс, можно включить один или оба (хотя бы один должен остаться включённым). По умолчанию 3 класс.
2. **Букв на выбор** — 2…4, по умолчанию 3. В датасете у каждого пропуска две буквы; если просят больше, добавляются похожие — гласная к гласной, согласная к согласной (сначала типичная пара `а/о`, `е/и`, потом любая буква того же рода). Пропуски с вариантом «нет буквы» не добираются: там выбор и так понятный.
3. **Количество слов** — 1…40, по умолчанию 10. Под степпером видно, сколько слов достанется каждому классу и сколько слов всего есть в выбранных классах.
4. **Работа над ошибками** — тумблер «Повторять мои ошибки» (по умолчанию включён) и за сколько последних тренировок смотреть ошибки (по умолчанию 5). Как в умножении и составе числа, ошибки **подмешиваются** в новые тренировки.

### Как формируется сессия

1. Если «Повторять мои ошибки» включено, сначала берутся слова с ошибками за последние X тренировок — через `VW.core.mistakesInScope()` (см. ниже). Если ошибок больше, чем слов в тренировке, берётся случайная часть.
2. Остаток делится между включёнными классами поровну (остаток — первым классам): 10 слов на два класса → 5 + 5.
3. Слова каждого класса перемешиваются, повторов внутри тренировки нет. Если в одном классе слов не хватило, недостача добирается из другого.
4. Повторы возможны только если слов запросили больше, чем есть в датасете.
5. Итоговый набор перемешивается.

### Слова другого класса в тренировку не попадают

Ошибки хранятся вместе с классом, но при сборке сессии класс берётся **не из
записи об ошибке, а из включённых в настройках**: слово проходит в тренировку
только если оно есть в списке включённого класса. Поэтому в режиме 2 класса
слова 3 класса не появятся, что бы ни лежало в истории, — и наоборот.

Обратная сторона того же правила: «морковь» и «помидор» есть в программе обоих
классов, поэтому ошибка на таком слове повторится в любом режиме, в каком бы
классе её ни записали.

Фильтр вынесен в `VW.core.mistakesInScope(grades, mistakes)` и вызывается из двух
мест — из сборки сессии и из подписи «слов для повторения» на странице настроек.
Так подпись не обещает того, чего в тренировке не будет: при 44 ошибках 3 класса
в режиме 2 класса она показывает «Слов для повторения: 2 (морковь, помидор).
Ещё 42 — из другого класса, не попадут».

Страница «Мои ошибки» — наоборот, показывает **все** сохранённые ошибки (ссылка на
неё так и называется, «все мои ошибки»), у каждого слова подписан класс. Её можно
распечатать целиком, независимо от того, какой класс сейчас выбран.

### Правила ответа

- Пропуски заполняются слева направо. Верная буква становится зелёной и встаёт на своё место, через полсекунды открывается следующий пропуск.
- Неверная буква — красная, кнопка выключается; можно выбирать дальше, пока не будет зелёной.
- Слово считается ошибкой, если **хотя бы в одном** пропуске была неверная попытка.
- Когда слово собрано, оно показывается целиком жирным — с подписью «прочитай слово вслух целиком».

### Подсказка «Показать слово»

Кнопка `🆘 Показать слово` открывает правильное слово целиком, чтобы прочитать его
по слогам и запомнить. Отмечается для слова один раз — сколько раз её ни открывай.
Цвета в итогах те же, что в сложении и вычитании: зелёная карточка — написал сразу,
**оранжевая** — верно, но смотрел слово (`✓ 💡`), красная — были ошибки. Ошибки
важнее подсказки.

### Страница ошибок

Слова за последние X тренировок: сверху слово с пропусками (`в_тер`), под ним ответ,
внизу класс и сколько раз ошибались. «Скрыть ответы» убирает ответ — можно
распечатать список слов с пропусками и вписать буквы в тетради.

### Данные в localStorage

- `vw.settings.v1` — настройки.
- `vw.history.v1` — последние 50 сессий: дата, счёт, `helped` (в скольких словах открывали подсказку), включённые классы, список ошибок (`word`, `grade`).
